# Norvalis AI

A modern AI chatbot application built with Flask, JavaScript, HTML and CSS, featuring real-time AI responses, conversation memory, multi-chat support and a multi-model architecture.

## Features

- AI-powered conversations using Google Gemini
- Streaming AI responses
- Conversation memory
- Multiple chat conversations
- Persistent chat history using localStorage
- Automatic chat title generation
- Chat search, rename, pin and delete
- TXT and Markdown conversation export
- Markdown rendering
- Syntax-highlighted code blocks
- Code block copy functionality
- AI message copy functionality
- Responsive chat interface
- Theme architecture
- AI model selector
- OpenRouter integration architecture

## Tech Stack

### Backend
- Python
- Flask
- Google GenAI SDK

### Frontend
- HTML5
- CSS3
- JavaScript
- Marked.js
- Highlight.js

### Storage
- Browser localStorage
